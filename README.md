## What it does

- digitizes a cafeteria's menu, allows the management to print out a custom menu daily
- keep tabs of the bakery items that are being bought/sold, along with statistics showing which ones are profit-making vs loss making
- daily bakery statistics can be exported into an excel file
- lets staff add, edit, and organize daily dish listings
- staff can add daily notes of what has been done, what needs to be done
- customizable to-do-checklist for employees to carry out before closing the store
- section that allows the staff/boss to create a section for 'pending reminders' and items that are low on supply
